# 宗派別お経マップ計画

## 目的

日本仏教の代表的な宗派ごとに、重視される経典や祖師文献を集め、埋め込みによって「宗派が参照するテキスト群の近さ」を可視化する。

これは宗派そのものを単純分類する実験ではない。宗派を、ひとつの教義ラベルではなく、複数のテキストへの関係として見る。

## 基本方針

- 経典全文を 1 本で埋め込まず、チャンク化してから平均ベクトルを作る。
- 同じ経典が複数宗派に共有される場合、本文は 1 回だけ保持し、manifest で複数宗派に紐づける。
- 所依経典、勤行で読まれる経典、祖師文献を分けて扱う。
- v0 は SAT と既存ローカルテキストで始め、外部取得や権利確認が難しい資料は後回しにする。

## レイヤー

- `core_sutra`: 所依経典・根本経典
- `chanting_sutra`: 勤行・法要で読まれる経典
- `founder_text`: 祖師文献
- `commentary`: 論・注釈書

## v0 の宗派と候補テキスト

### 天台宗

- 法華経
- 涅槃経
- 摩訶止観

仮説:

- 法華経を中心に、日蓮宗と近く出る。
- 祖師文献を入れると、日蓮宗とは別方向が見える可能性がある。

### 真言宗

- 大日経
- 金剛頂経
- 理趣経
- 般若心経

仮説:

- 密教経典群が、浄土・法華・禅系とは別方向に出る。

### 浄土宗

- 無量寿経
- 観無量寿経
- 阿弥陀経
- 往生論

仮説:

- 浄土三部経がまとまり、浄土真宗とも近く出る。
- 祖師文献を入れると、浄土宗と浄土真宗の違いが見えやすくなる。

### 浄土真宗

- 無量寿経
- 観無量寿経
- 阿弥陀経
- 教行信証
- 正信偈

仮説:

- 経典だけでは浄土宗と近い。
- 教行信証・正信偈を入れると、親鸞文献の引用構造と用語が別の重心を作る。

### 日蓮宗

- 法華経
- 無量義経
- 観普賢経

仮説:

- 法華経を中心に天台宗と近い。
- 日蓮遺文を入れると、法華経中心性がより強く見える可能性がある。

### 曹洞宗

- 般若心経
- 観音経
- 修証義
- 正法眼蔵系文献

仮説:

- 経典だけでは臨済宗と分かれにくい。
- 修証義や道元文献を入れると曹洞宗らしい方向が出る。

### 臨済宗・黄檗宗

- 般若心経
- 観音経
- 金剛経
- 維摩経
- 禅語録

仮説:

- 経典だけでは曹洞宗と近い。
- 語録・祖師文献を入れると、禅系内部の違いが見える可能性がある。

### 華厳宗

- 華厳経

仮説:

- 華厳経は大部で、単一経典内のチャンク分布を見る価値が高い。

### v1 以降

- 法相宗: 解深密経、瑜伽師地論、成唯識論
- 律宗: 四分律、梵網経
- 時宗: 浄土三部経、念仏系文献

## 可視化

- 点: 経典または祖師文献
- 四角: 宗派重心
- 色: 主に紐づく宗派
- 形: レイヤー
- クリック時:
  - 経典名
  - SAT ID
  - 紐づく宗派
  - レイヤー
  - 近い経典
  - 代表チャンク
  - 出典リンク

## 最初の成功条件

- 浄土三部経がまとまるか確認できる。
- 法華経系が天台・日蓮の中心に来るか確認できる。
- 真言系の密教経典が別方向に出るか確認できる。
- 禅宗系は経典だけだと曹洞・臨済が分かれにくいか確認できる。
- 祖師文献を足すと、宗派差が強く出るか確認できる。
