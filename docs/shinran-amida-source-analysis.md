# 親鸞の阿弥陀経二訳参照分析メモ

## 目的

親鸞が『阿弥陀経』をどの漢訳・注釈伝統を通して読んでいるかを、計算的に探索するための予備実験である。対象は、鳩摩羅什訳 `T0366`『佛説阿彌陀經』、玄奘訳 `T0367`『稱讃淨土佛攝受經』、親鸞文献側の『教行信証』および『入出二門偈』p543 とした。

この実験では、意味埋め込みだけで判断しない。阿弥陀経二訳は意味的に非常に近く、埋め込みだけでは訳の系統差が潰れやすいためである。そこで次の三層を分けた。

- 明示引用: 経名・訳者名を名指しするか。
- 訳語・句の証拠: 羅什訳固有に近い語句、玄奘訳固有に近い語句が出るか。
- 意味近傍: 既存 chunk embeddings で、親鸞文献の各チャンクが二訳のどちらに近いか。

## 主要結果

### 1. 『入出二門偈』は玄奘訳を明示する

真宗聖典検索 p543 では、『入出二門偈頌文』冒頭に『称讃浄土経』と玄奘三蔵訳であることが明示される。さらに、百千倶胝の舌・無量の声によっても功徳を讃め尽くせない、という玄奘訳側の讃嘆モチーフに対応する句が出る。

このため、『入出二門偈』については、玄奘訳 `T0367` の直接利用または少なくとも明示的参照があると見てよい。

### 2. 『教行信証』は意味的には二訳に近いが、決定打は弱い

『教行信証』本文平均ベクトルは、次のようになった。

| Comparison | Cosine |
| --- | ---: |
| 教行信証 → 羅什訳 `T0366` | `0.8058` |
| 教行信証 → 玄奘訳 `T0367` | `0.8152` |

玄奘訳の方がわずかに高いが、差は `0.0094` と小さい。阿弥陀経二訳そのものが近いため、この差だけで「どちらを元にした」とは言えない。

### 3. 『教行信証』のチャンク近傍は二訳にまたがる

教行信証チャンクの上位近傍には、羅什訳 `T0366` の因果段・発願段に近いものと、玄奘訳 `T0367` の極楽荘厳・讃嘆段に近いものが混在する。

| Target | Kyogyoshinsho chunk | Target chunk | Cosine |
| --- | --- | --- | ---: |
| `T0366` | `kyogyoshinsho::chunk_0098` | `t0366_amida_sutra::chunk_0005` | `0.7250` |
| `T0366` | `kyogyoshinsho::chunk_0019` | `t0366_amida_sutra::chunk_0005` | `0.7103` |
| `T0366` | `kyogyoshinsho::chunk_0018` | `t0366_amida_sutra::chunk_0005` | `0.7088` |
| `T0367` | `kyogyoshinsho::chunk_0023` | `t0367_praise_pure_land::chunk_0006` | `0.7033` |

### 4. 文字列証拠では『教行信証』に羅什訳系の句も出る

正規化後の完全一致では、『教行信証』と羅什訳 `T0366` の間に、六方諸仏の証誠段に関わる句、臨終・往生に関わる句が検出された。玄奘訳 `T0367` との完全一致は、現段階では汎用的な仏教語句に留まりやすい。

これは『教行信証』が三部経を根拠にしつつ、特定の阿弥陀経異訳だけに単純に還元できないことを示す。

### 5. 『阿弥陀経集註』が次の本命資料

『観無量寿経集註附阿弥陀経集註』は、若き親鸞が『観経』と『阿弥陀経』に註記を施した資料として重要である。名古屋大学書誌では、親鸞壮年時代の自筆本とされ、法然門下で学んでいた時期の資料と説明されている。千葉論文は、この『阿弥陀経集註』における元照『阿弥陀経義疏』引文を扱っている。

したがって次の段階では、『阿弥陀経集註』本文を取得し、経文本文、行間註、裏書を分けて解析する必要がある。

## 解釈

現段階で言えることは、以下である。

- 羅什訳 `T0366` は、浄土三部経の標準的な『阿弥陀経』として、親鸞の阿弥陀経理解の基本層にある。
- 玄奘訳 `T0367` は、『入出二門偈』で明示的に参照され、讃嘆モチーフも利用されている。
- 『教行信証』では、意味的には `T0366`・`T0367` の両方に近く、テキスト全体平均では玄奘訳がわずかに高いが、決定的ではない。
- 親鸞の阿弥陀経理解は、「どちらの訳か」という二択よりも、三部経、異訳、善導・元照などの注釈伝統を重ねたものとして扱う方がよい。
