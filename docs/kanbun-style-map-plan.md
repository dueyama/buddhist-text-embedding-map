# 日本漢文・変体漢文スタイルマップ計画

## 目的

お経の意味的な近さを埋め込みで見る実験とは別に、古事記・日本書紀・風土記などの上代日本の漢字文献について、「中国人が書いた漢文」と「日本人が書いた漢文・漢字文」の違いを計量的に見る。

特に見たいのは、内容の近さではなく、文体・語法・用字の癖である。

- 中国古典文に近い文章
- 日本で正格漢文を志向して書かれた文章
- 和習・倭習の強い文章
- 古事記のように、単純な漢文ではなく倭文体として扱うべき文章

これらを同じ空間に置き、意味マップとは別の「文体マップ」として可視化する。

## 背景メモ

この領域では、次の研究・用語が重要そう。

- 森博達による日本書紀の分析
  - 漢字音・語法などから、日本書紀を中国人系の書き手による部分と日本人が書き継いだ部分に分ける議論。
  - いわゆる日本書紀の alpha 群・beta 群が、計量実験のよい教師データになりそう。
- 変体漢文・倭文体
  - 古事記などを単純に「変体漢文」と呼ぶのが適切かどうかは研究史上の論点がある。
  - 古事記は「漢文を誤ったもの」ではなく、日本語を漢字文として表す独自の文体として見た方がよい可能性がある。
- 和習・倭習
  - 日本語に引っぱられた語順、語法、用字、語気など。
  - 最近の計量研究では、助字の頻度から中国漢文・正格漢文・変体漢文を判別する試みがある。

## まず扱いたいテキスト候補

### 中国漢文の対照群

既存の探索用フォルダに、文字 n-gram や助字頻度を試したコードがいくつかある。

- 論語
- 老子
- 孟子
- 韓非子
- 戦国策
- 史記の一部

目的:

- 「中国漢文らしさ」の対照群にする。
- 文字 n-gram と助字頻度のベースラインにする。

### 日本側の主要候補

- 古事記
  - 序文と本文は分けて扱う。
  - 本文は倭文体・変体漢文の中心候補。
  - 万葉仮名的・音仮名的な部分をどう扱うかが課題。
- 日本書紀
  - alpha 群・beta 群を分けて扱う。
  - 森博達の区分をベンチマークにできる。
  - 巻単位で分割すると検証しやすい。
- 風土記
  - 日本語地名・伝承・漢文体が混ざる資料として面白い。
- 正倉院文書
  - 行政文書・実用文体として、古事記や日本書紀とは違う方向の和習が見える可能性がある。
- 古語拾遺
  - 日本側の古代氏族伝承系テキストとして候補。
- 続日本紀などの六国史
  - 日本で書かれた正史漢文として、日本書紀との連続性を見る候補。

### あとで混ぜたい比較対象

- 平安期の古記録
- 江戸期の日本漢文
- 漢訳仏典
- 日本の祖師文献

これらは最初から混ぜると解釈が散るので、初回実験では優先度を下げる。

## 分析軸

### 1. 意味ベクトル

OpenAI embeddings などで、内容・主題の近さを見る。

ただし今回の主目的ではない。古事記・日本書紀・史記などは主題差が強く出すぎる可能性があるため、文体比較では補助的に使う。

### 2. 文体ベクトル

今回の中心。

候補特徴量:

- 文字 n-gram TF-IDF
  - 2-gram から 5-gram 程度。
  - 既存の阿弥陀経比較でも、語彙・言い回しの差を見るには有効だった。
- 助字頻度
  - 之, 其, 而, 以, 於, 于, 乎, 者, 也, 矣, 焉, 哉, 所, 為, 被, 見, 令, 使, 不, 無, 莫, 有, 如, 若 など。
  - 作品長で正規化する。
- 文末表現
  - 也, 矣, 焉, 耳, 云, 曰, 乎, 哉 など。
- 前置詞・介詞的表現
  - 於, 于, 以, 從, 自, 與, 為 など。
- 受身・使役・待遇表現に関わる助字
  - 被, 見, 為, 所, 令, 使 など。
  - 和習判別研究で重要そう。
- 用字・語彙の癖
  - 同じ意味でどの字を選ぶか。
  - 固有名詞・地名・神名の表記。
- 音仮名・万葉仮名的な部分
  - 古事記では特に重要。
  - 初回は除外せず特徴量として残す。あとで本文種別ごとに分ける。

### 3. ラベル

最初は厳密にしすぎず、仮ラベルでよい。

- `chinese_classical`: 中国古典
- `seikaku_kanbun`: 正格漢文寄り
- `japanese_kanbun`: 日本人による漢文
- `hentai_kanbun`: 変体漢文
- `yamato_style`: 倭文体
- `kundoku_related`: 訓点・訓読関連資料

古事記の扱いは `hentai_kanbun` と断定せず、`yamato_style` として別枠を用意する。

## 可視化したいもの

- 2D マップ
  - 点 = テキストまたはチャンク
  - 色 = 仮ラベル
  - 形 = ジャンル、時代、地域
- 類似度ヒートマップ
  - 文字 n-gram 類似度
  - 助字頻度類似度
  - 意味埋め込み類似度
- alpha/beta 検証ビュー
  - 日本書紀の巻ごとに文体ベクトルを置く。
  - 森説の alpha 群・beta 群とどれくらい一致するかを見る。
- 特徴量ビュー
  - どの助字・n-gram が分類に効いたかを表示する。
  - 単なるクラスタリングで終わらせず、説明可能にする。

## 最初の実験案

### 実験 A: 中国漢文 vs 既存ローカル漢文テキスト

目的:

- 既存の探索用コードにある文字 n-gram と助字頻度が安定して動くか確認する。

成功条件:

- 同じ作品のチャンクが大きく散らばりすぎない。
- 作品ごとの特徴量上位が解釈できる。

### 実験 B: 古事記を追加

目的:

- 古事記が中国漢文対照群から文体的に離れるかを見る。
- 序文と本文の差を見る。

成功条件:

- 古事記本文が中国漢文群と別方向に出る。
- 序文と本文が同じ作品内でも違う位置に出る。
- 差を説明する特徴量が出る。

### 実験 C: 日本書紀 alpha/beta 検証

目的:

- 既存研究で知られる alpha 群・beta 群の差を、こちらの特徴量で再現できるかを見る。

成功条件:

- 巻単位またはチャンク単位で alpha/beta がある程度分かれる。
- 分類に効いた特徴量が、助字・語法・用字の差として説明できる。

### 実験 D: 意味ベクトルとのズレを見る

目的:

- 意味的には近いが文体的には遠い、またはその逆を見つける。

成功条件:

- semantic map と style map の配置が異なる例を提示できる。
- 「内容」ではなく「書き方」を見ていることを説明できる。

## 注意点

- これは思想分類ではなく文体分類の実験として始める。
- 古事記を「誤った漢文」として扱うのは避ける。
- 近代校訂本文や現代語訳には著作権がありうるので、本文データの利用条件を必ず確認する。
- 句読点や段落は現代編集者が付けた可能性があるため、文体特徴としてそのまま信用しない。
- 既存研究の区分を答えとして丸写しするのではなく、再現できるかを検証対象にする。
