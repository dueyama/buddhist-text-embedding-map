## 2026-06-02 対応範囲

今回の改稿では、査読コメントのうち、予備論文として説得力に直結する項目を優先して反映した。

## 対応済み

- タイトルを「宗派的配置・訳者差」中心から、「探索地図・宗派別参照群・異訳比較」中心へ変更。
- 「宗派別お経マップ」「宗派重心」という強い表現を、「宗派別参照テキスト群の意味配置」「宗派別参照群重心」へ弱めた。
- 対象テキスト表に、出典、全文性、文字数、チャンク数、備考を追加。
- チャンク化方法、`tiktoken` tokenizer、700 tokens / 100 overlap、自然境界未使用、前処理、L2正規化の有無、PCA seed を明記。
- PCA寄与率を本文および図軸に追加。
- 阿弥陀経二訳の `0.8943` と `0.8825` の差を、全文直接埋め込みとチャンク平均ベクトルの違いとして整理。
- チャンク近傍混合率の top-k 感度分析を追加。
- ラベルシャッフル検定は、通常の「観測値がランダムより高い」検定としては不適切であることを明記し、完全混合に近い参照値として扱った。
- 訳者差、多言語対応、禅系の宗派差について、断定を避ける表現に修正。
- 意味マップ、文体マップ、引用・参照マップの三層モデルを考察に追加。
- 親鸞文献分析の図キャプションに、宗派別参照群マップ本体とは別の引用・参照ソース小実験であることを明記。
- stylometry と漢訳仏典語彙研究に関する参考文献を追加。
