Paper

The Japanese paper is the authoritative print/book edition. The English page is an AI-assisted translation for access by English-language readers.

Code

The repository includes scripts for corpus building, embeddings, viewer data, and figure generation. API keys and caches are not included.

Viewer

The public viewer omits raw text previews and shows metadata, coordinates, similarities, and nearest-neighbor identifiers.

Process

The process report records repository setup, experiments, review-style revision, HTML/PDF papers, and GitHub Pages preparation.

Publication Scope

Raw texts from SAT, J-SOKEN, 84000, and related providers are not redistributed. The public repository focuses on source URLs, procedures, figures, papers, and derived similarity or coordinate data.
