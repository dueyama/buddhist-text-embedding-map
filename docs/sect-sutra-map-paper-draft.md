# 意味埋め込みを用いた漢訳仏典の宗派的配置と訳者差の予備的検討

著者: 未定  
日付: 2026-06-01  
種別: 研究ノート・予備実験ドラフト v0.1

## 要旨

本稿は、漢訳仏典および日本撰述仏教文献を対象に、意味埋め込みによって宗派別の参照テキスト群を可視化できるかを検討する予備的研究である。対象には、浄土系、法華系、真言系、禅系、華厳系、法相系に関係する 15 テキストを用いた。各本文をチャンク化し、`text-embedding-3-large` によってチャンク埋め込みを作成し、本文単位のベクトルはチャンクベクトルの平均として得た。さらに、宗派重心と訳者重心を計算し、静的ウェブビューア上で 2 次元配置、類似度ヒートマップ、近傍テキストを確認した。

結果として、阿弥陀経とその玄奘訳別訳である『稱讃淨土佛攝受經』は、訳者が異なるにもかかわらず高い類似度を示した。一方で、玄奘訳の複数テキストは、訳者のみを理由に強くまとまるわけではなかった。これは、意味埋め込みが主として内容・主題の近さを捉え、訳語選択や文体上の癖は別の特徴量として扱う必要があることを示唆する。また、浄土三部経や真言系密教経典には一定のまとまりが見られたが、禅系については経典のみでは宗派差を十分に表現できなかった。

## キーワード

漢訳仏典、宗派比較、意味埋め込み、阿弥陀経、玄奘、鳩摩羅什、仏教文献情報学

## 1. はじめに

日本仏教の各宗派は、それぞれ特定の経典、祖師文献、儀礼的読誦テキストを重視してきた。たとえば浄土系では浄土三部経および祖師文献が重要であり、真言宗では大日経、金剛頂経、理趣経などの密教経典が中心的な位置を占める。一方、禅宗では般若心経、金剛経、維摩経などが参照されるが、宗派的特徴は経典そのものよりも語録、清規、祖師文献に強く現れる可能性がある。

近年の大規模言語モデルおよび埋め込みモデルは、テキストの意味的近さを高次元ベクトルとして表現できる。本研究では、この手法を仏教文献に適用し、宗派ごとの参照テキスト群の配置を可視化できるかを検討する。あわせて、阿弥陀経の異訳や同一訳者の複数テキストを用い、意味的近さと翻訳文体の差がどのように現れるかを予備的に確認する。

本稿の目的は、宗派分類の正解モデルを作ることではない。むしろ、各宗派が参照するテキスト群を意味空間上に置いたとき、どのような近接関係や解釈上の問題が現れるかを把握することである。

## 2. 研究課題

本稿では、以下の三つの問いを設定する。

1. 意味埋め込みによって、浄土三部経や真言系密教経典のような主題的まとまりを確認できるか。
2. 宗派ごとの参照テキスト群を重心として可視化した場合、宗派の特徴をどの程度表現できるか。
3. 阿弥陀経の異訳および同一訳者の複数テキストを比較したとき、意味の近さと翻訳文体の差を区別できるか。

## 4. 方法

### 4.1 チャンク化

本文は既定で 700 トークン、100 トークンの重なりによりチャンク化した。経典の巻・品などによる自然分割は v0.1 では十分に利用しておらず、今後の改善対象である。

### 4.2 埋め込み

各チャンクに対して `text-embedding-3-large` による埋め込みを作成した。同一モデル・同一本文のチャンクについてはキャッシュを利用し、再実行時に API を呼び直さないようにした。本文単位のベクトルは、当該本文に属するチャンクベクトルの平均として計算した。

### 4.3 類似度と重心

本文間の類似度はコサイン類似度によって計算した。宗派重心は、当該宗派に属する `core_sutra` および `founder_text` の本文ベクトルの平均として定義した。訳者重心は、同一訳者に属する複数テキストの本文ベクトルの平均として定義した。ただし、今回の訳者重心はサンプル数が少ないため、可視化上の補助線として扱う。

### 4.4 可視化

本文ベクトル、宗派重心、訳者重心を同一空間に配置し、2 次元表示には PCA を用いた。静的ウェブビューアでは、2 次元マップ、類似度ヒートマップ、詳細パネル、近傍テキスト、近傍チャンク、宗派・レイヤーフィルタを確認できる。

### 4.5 阿弥陀経二訳の文体比較

阿弥陀経二訳については、意味埋め込みに加えて文字単位 TF-IDF も計算した。文字単位 TF-IDF では 2 から 5 文字の n-gram を用いた。これは、意味的近さではなく、語彙選択や表記の差を捉えるための簡易的な対照実験である。

## 5. 結果

### 5.1 阿弥陀経二訳

鳩摩羅什訳『佛説阿彌陀經』と玄奘訳『稱讃淨土佛攝受經』を比較したところ、意味埋め込みでは高い類似度を示した。一方、文字単位 TF-IDF では低い類似度となった。

| 方法 | 全文レベルのコサイン類似度 | チャンク間最良一致の平均 |
| --- | ---: | ---: |
| 文字単位 TF-IDF | 0.1928 | 0.1424 |
| OpenAI 埋め込み | 0.8943 | 0.7108 |

この差は、両テキストが内容としては近い一方で、訳語や表現には大きな違いがあることを示す。たとえば、鳩摩羅什訳では `舍利弗`、`衆生`、`阿彌陀佛`、`恒河沙` が目立つのに対し、玄奘訳では `舍利子`、`有情`、`無量壽佛`、`殑伽沙` が対応する表現として現れる。

### 5.2 宗派別お経マップ

15 テキスト、433 チャンクからビューアデータを作成した。宗派重心は 11、訳者重心は 3 であった。阿弥陀経から見た近傍は次の通りである。

| 基準テキスト | 近傍テキスト | コサイン類似度 |
| --- | --- | ---: |
| 阿弥陀経 | 稱讃淨土佛攝受經 | 0.8825 |
| 阿弥陀経 | 無量寿経 | 0.8694 |
| 阿弥陀経 | 観無量寿経 | 0.8446 |
| 阿弥陀経 | 妙法蓮華経抜粋本文 | 0.8275 |
| 阿弥陀経 | 教行信証 | 0.8058 |

浄土三部経は、阿弥陀経から見た場合に無量寿経・観無量寿経が上位に現れ、浄土系のまとまりが確認できた。また、玄奘訳別訳である『稱讃淨土佛攝受經』が最上位に現れることから、同内容・近内容の経典が訳者差を越えて近く表現されている。

真言系では、大日経、金剛頂経、理趣経の間に比較的高い類似度が見られた。

| 基準テキスト | 近傍テキスト | コサイン類似度 |
| --- | --- | ---: |
| 金剛頂経 | 理趣経 | 0.8405 |
| 金剛頂経 | 大日経 | 0.8323 |
| 理趣経 | 大日経 | 0.8512 |

一方、禅系については、経典のみでは曹洞宗・臨済宗・黄檗宗の差は明確に出なかった。これは、禅宗の宗派差が経典よりも祖師文献、語録、清規、修行実践の言説に現れる可能性を示す。

### 5.3 訳者重心

訳者重心は、不空、玄奘、鳩摩羅什の 3 種を作成した。

| 訳者 | テキスト数 | 対象 |
| --- | ---: | --- |
| 不空 | 2 | 金剛頂経、理趣経 |
| 玄奘 | 3 | 稱讃淨土佛攝受經、般若心経、解深密経 |
| 鳩摩羅什 | 5 | 阿弥陀経、法華経、観音経相当部分、金剛経、維摩経 |

玄奘訳『稱讃淨土佛攝受經』の近傍は、同じ玄奘訳の般若心経や解深密経ではなく、鳩摩羅什訳『阿弥陀経』および浄土系経典であった。

| 基準テキスト | 近傍テキスト | コサイン類似度 |
| --- | --- | ---: |
| 稱讃淨土佛攝受經 | 阿弥陀経 | 0.8825 |
| 稱讃淨土佛攝受經 | 無量寿経 | 0.8798 |
| 稱讃淨土佛攝受經 | 妙法蓮華経抜粋本文 | 0.8469 |
| 稱讃淨土佛攝受經 | 観無量寿経 | 0.8412 |
| 稱讃淨土佛攝受經 | 教行信証 | 0.8152 |

また、玄奘訳『解深密経』は、同一訳者であることよりも内容的な近さに従って配置されていると見られる。

| 基準テキスト | 近傍テキスト | コサイン類似度 |
| --- | --- | ---: |
| 解深密経 | 教行信証 | 0.8548 |
| 解深密経 | 大日経 | 0.8478 |
| 解深密経 | 維摩経 | 0.8370 |
| 解深密経 | 金剛経 | 0.8308 |
| 解深密経 | 無量寿経 | 0.7838 |

この結果から、今回の意味埋め込みでは、訳者差よりも主題・内容の影響が強いことが示唆される。

## 6. 考察

### 6.1 意味埋め込みが捉えるもの

阿弥陀経二訳の結果は、意味埋め込みが語彙差や訳語差を越えて、内容の近さを強く捉えることを示している。これは、同一または近接する原内容の漢訳を検出する用途には有用である可能性がある。

一方で、文字単位 TF-IDF では阿弥陀経二訳の類似度が低く出た。これは、文体、訳語、語彙選択、固有名詞表記の差が文字 n-gram 特徴に強く反映されるためである。したがって、意味の近さと翻訳上の癖は、同一のベクトル空間で同時に扱うよりも、意味ベクトルと文体ベクトルを分けて扱う方がよい。

### 6.2 宗派マップの解釈

浄土系と真言系では、中心的な経典群が比較的まとまりやすい傾向が見えた。ただし、これは宗派そのものを分類したというより、宗派が重視するテキスト群の主題的近接を可視化した結果である。

また、教行信証のような祖師文献は、多数の引用や教義的総合を含むため、単一経典とは異なる振る舞いを示す。本文平均ベクトルでは、引用元や関連主題が混ざり、宗派性だけでなく文献の総合性が反映される可能性がある。

禅系については、経典のみでは宗派差が分かれにくかった。これは失敗というより、投入データが宗派差を表す層に届いていないことを示す結果である。禅宗の比較には、碧巌録、無門関、正法眼蔵、臨済録、黄檗清規などの祖師文献・語録・規範文献を加える必要がある。

### 6.3 訳者差を見るための課題

訳者重心は、ビューア上で訳者ごとのテキスト分布を確認する補助線としては有用である。しかし、意味埋め込みの平均ベクトルだけでは、訳者の文体的特徴を直接抽出するには不十分である。特に、玄奘訳『稱讃淨土佛攝受經』が同じ玄奘訳の『解深密経』よりも鳩摩羅什訳『阿弥陀経』に近いことは、モデルが訳者より内容を優先していることを示す。

翻訳癖を扱うには、少なくとも次の特徴量を別途作る必要がある。

- 文字 n-gram
- 助字や虚詞の頻度
- 文長・句構造
- 固有訳語の対応関係
- 音写語と意訳語の選択
- 同一サンスクリット語に対する漢訳語の揺れ

## 7. 限界

本研究には以下の限界がある。

1. コーパスが小さく、宗派ごとの代表性が十分ではない。
2. 大部経典の一部は SAT の直接表示範囲または既存取得の抜粋であり、全文比較ではない。
3. 宗派重心は単純平均であり、宗派内での重要度や歴史的受容の重みを考慮していない。
4. 訳者重心はサンプル数が少なく、訳者特徴として統計的に安定していない。
5. PCA による 2 次元配置は可視化用であり、距離の厳密な解釈にはヒートマップや近傍リストを併用する必要がある。
6. 現時点では文体ベクトルが未実装であり、翻訳文体の分析は予備的段階にとどまる。

## 8. 今後の課題

今後は、以下の方向で実験を拡張する。

1. SAT から各経典の全文を安定して取得し、抜粋と全文の差を検証する。
2. 各宗派について、経典だけでなく祖師文献、語録、儀礼文、注釈書を追加する。
3. 意味ベクトルとは別に文体ベクトルを作成し、翻訳者・時代・日本撰述漢文の特徴を可視化する。
4. 宗派重心に重み付けを導入し、中心経典、勤行テキスト、祖師文献を区別する。
5. 類似度だけでなく、クラスタリング指標、近傍安定性、チャンク単位の局所類似を評価する。
6. 日本漢文・変体漢文の文体マップへ同じ基盤を展開する。

## 9. 結論

本予備実験では、意味埋め込みを用いることで、阿弥陀経二訳のような同内容・近内容テキストの近接、および浄土系・真言系経典群の一定のまとまりを確認できた。一方で、訳者差や宗派差を精密に捉えるには、意味埋め込みだけでは不十分である。特に訳者の癖を分析するには、文字 n-gram、訳語対応、助字、句法などを用いた文体特徴量を別レイヤーとして導入する必要がある。

したがって、本研究の現段階の成果は、宗派分類器の完成ではなく、仏教文献群を探索するための意味地図の基盤を構築した点にある。今後、データを拡張し、意味マップと文体マップを重ねることで、宗派、訳者、時代、日本撰述漢文の差異をより精密に検討できると考えられる。
